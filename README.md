# MusicOnline

A PHP and MySQL web application developed as part of my HND Software Development studies.

## Overview

MusicOnline is a music catalogue and marketplace application that allows users to browse albums, create accounts and manage listings. The project was developed to demonstrate database integration, user authentication and web development skills.

The application includes both user and administrator functionality, providing different levels of access and management features.

## Features

### User Features

- User registration and login
- Account management
- Browse music listings
- View album details
- Create and manage personal listings
- Upload album artwork
- Search catalogue

### Administrator Features

- View all users
- Edit user information
- Delete users
- Manage listings
- Access administrator dashboard
